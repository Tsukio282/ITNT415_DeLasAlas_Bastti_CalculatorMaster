\*\*Student Name:\*\* Bastti Mikael C. De Las Alas

\## Project Description

A simple menu-driven Python calculator application developed to demonstrate software version control using Git and GitHub. The project showcases continuous execution, user input validation, and proper error handling.



\## Branch Structure

The project contains the ff:

\* `main`: Core calculator skeleton and final integrated application.

\* `addition\_DeLasAlas`: Addition operation logic.

\* `subtraction\_DeLasAlas`: Subtraction operation logic.

\* `multiplication\_DeLasAlas`: Multiplication operation logic.

\* `division\_DeLasAlas`: Division operation logic with zero-division handling.



\## Program Features

\* Menu-driven interface with continuous execution, and I made it pink \& purple colour scheme.

\* Performs addition, subtraction, multiplication, and division.

\* User input validation for non-numerical entries.

\* Explicit error handling protecting against division-by-zero.
